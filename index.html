Data Management Instructions

Overview:

Your data is stored locally in your browser, so it's important to back it up regularly by exporting it. This also allows you to share data with others.

Exporting Data:

  • Export to JSON: Click this button to save all your WEBLOG entries to a .json file. The file will be named according to the date and time of export, e.g., weblogs_2025-09-09_12-47-41.json. This is the most comprehensive format for backups.
  • Export to CSV: Click this button to save all your data to a .csv file, which can be opened in Microsoft Excel, Google Sheets, or other spreadsheet editors. This format is convenient for analysis and creating reports.

Important Note on Saving:

Browsers do not have direct access to network drives. When you export a file, it will be saved to your computer's "Downloads" folder. To share your data, you will need to manually move this file to the shared network folder:

\\Flsala\Engineering_&_Maintenance\Technical Resources\WebLogs Data Export

Importing Data:

  • Import from JSON: Click this button to select a .json file from your computer (or from a network drive). Warning: Imported data will replace all your current entries. It is recommended to back up your data before importing.
