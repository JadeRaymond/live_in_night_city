# Reelkeep — сборка и состав архива для внешнего разбора

Снимок исходников: версия 1.23, versionCode 34, пакет `com.reelkeep.app`.
Исходный проект расположен в `/workspace/reelkeep`.
После распаковки корень проекта — папка, содержащая этот файл, `build.sh` и `app/`.

## Состав

- Все 33 Java-файла из `app/src/com/reelkeep/app/`, без изменения содержимого.
- Исходный `app/AndroidManifest.xml` из проекта, не декомпилированный из APK.
- Вся существующая папка `app/res/`: drawable и values/styles.
- `build.sh` — копия скрипта проекта с удалёнными реквизитами подписи.
- Этот `BUILD.md`.

Gradle в этой конфигурации не используется: файлов `build.gradle`, `settings.gradle`
и `gradle.properties` в корне проекта нет.

## Окружение

- Android SDK Platform API 35; заголовки: `tools/android-35/android.jar`.
- Android SDK Build Tools 35.0.0; в текущем проекте установлен в исторически
  названную папку `tools/android-15/`. Номер папки НЕ означает версию build-tools.
- `compileSdk`: 35; `minSdk`: 26; `targetSdk`: 32 (см. исходный манифест).
- Проверенное окружение: OpenJDK 21.0.13.
- Java-компилятор Eclipse ECJ (`tools/ecj.jar`), параметр `-8`: Java 8.
- Утилиты: Bash, Java, zip, aapt2, D8, zipalign, apksigner.

## Команда сборки

В полном исходном рабочем проекте:

```sh
cd /workspace/reelkeep
bash build.sh
```

В распакованной копии при восстановленных зависимостях:

```sh
cd /path/to/Reelkeep-source-review-1.23
bash build.sh
```

Копия скрипта определяет корень по собственному расположению.
Последовательность: aapt2 compile/link → ECJ → D8 → упаковка dex и native libs →
zipalign → подпись и проверка apksigner.
Выход основного скрипта: `build/reelkeep.apk` (состав ABI зависит от подготовленных native libs).
В опубликованной телефонной сборке 1.23 оставлен только `arm64-v8a`:
из APK исключаются другие ABI и старая подпись, затем выполняются zipalign
и повторная подпись. Готовый релиз в рабочем окружении:
`/workspace/library-files/Reelkeep-1.23.apk`.
APK в этот архив не включён.

## Внешние зависимости и ограничения

Это строго запрошенный архив для анализа, а не самодостаточная сборочная среда.
Он НЕ собирается изолированно без восстановления зависимостей и ресурсов:

- Android SDK, build-tools и ECJ.
- `tools/ort.jar` (ONNX Runtime) и `tools/tess.jar` (Tesseract Java API).
- Подготовленные нативные библиотеки в `build/native/lib/`.
- `app/assets/`: WebView-интерфейс и ресурсы приложения. Эта папка не входит
  в запрошенный перечень экспорта и целиком оставлена за пределами архива.
  Для полноценного воспроизведения интерфейса отдельно нужны её HTML/CSS/JS,
  локализации, а для всех возможностей — модели, OCR-данные, шрифты и runtime.

В архиве нет `tools/`, `app/assets/`, `build/`, `.gradle/`, `outputs/`, SDK/JAR/AAR,
SO, ONNX, traineddata, TTF, WHL и исполняемых файлов yt-dlp.
Скрипт не загружает и не подменяет эти отсутствующие зависимости автоматически.

## Подпись

Релиз подписывается локально Android `apksigner` с существующим keystore
после `zipalign`. Сам keystore, ключи и пароли отсутствуют в архиве.

Экспортная копия `build.sh` берёт путь к ВНЕШНЕМУ keystore из
`REELKEEP_KEYSTORE`, а пароль — из переменной окружения `REELKEEP_KS_PASS`
через механизм `apksigner --ks-pass env:...`. Значения необходимо передать
самостоятельно через безопасное окружение. Никаких готовых значений в архиве нет.
Автоматическое создание ключа из исходного рабочего скрипта удалено.
При отдельном пароле ключа потребуется соответствующий параметр apksigner.
Для установки обновления поверх существующего приложения нужна та же подпись;
другой ключ даёт другую подпись.

## Отличия экспортной копии скрипта

1. Абсолютный `cd` заменён определением каталога самого скрипта.
2. Удалена команда создания keystore с встроенными реквизитами.
3. Путь и пароль подписи заменены внешними переменными окружения.
Остальная последовательность сборки сохранена; рабочий проект и его ключ не изменялись.

## Данные и учётные записи

Пользовательский каталог, cookies, сессии Instagram, токены и прочие учётные
данные не экспортировались. Упоминания CookieManager и названий полей сессии
в Java — исходный код обработки данных, а не сохранённая сессия.

package com.reelkeep.app;

import android.content.*;
import android.database.Cursor;
import android.database.MatrixCursor;
import android.net.Uri;
import android.os.ParcelFileDescriptor;
import android.provider.OpenableColumns;
import java.io.*;

/** Private provider with temporary read grants for exactly one installed APK. */
public final class ApkShareProvider extends ContentProvider {
    public boolean onCreate() { return true; }
    private File apk(Uri uri) throws FileNotFoundException {
        if (!ApkSharing.uri(getContext()).equals(uri)) throw new FileNotFoundException("Unknown file");
        try { return ApkSharing.installed(getContext()); }
        catch (IOException error) { throw new FileNotFoundException(error.getMessage()); }
    }
    @Override public ParcelFileDescriptor openFile(Uri uri, String mode) throws FileNotFoundException {
        if (!"r".equals(mode)) throw new FileNotFoundException("Read only");
        return ParcelFileDescriptor.open(apk(uri), ParcelFileDescriptor.MODE_READ_ONLY);
    }
    public String getType(Uri uri) {
        if (!ApkSharing.uri(getContext()).equals(uri)) throw new IllegalArgumentException("Unknown file");
        return ApkSharing.MIME;
    }
    public Cursor query(Uri uri, String[] projection, String selection, String[] args, String order) {
        File file;
        try { file = apk(uri); } catch (IOException error) { return null; }
        String[] columns = projection == null ? new String[]{OpenableColumns.DISPLAY_NAME, OpenableColumns.SIZE} : projection;
        MatrixCursor result = new MatrixCursor(columns, 1);
        Object[] row = new Object[columns.length];
        for (int i = 0; i < columns.length; i++) {
            if (OpenableColumns.DISPLAY_NAME.equals(columns[i])) row[i] = ApkSharing.filename(getContext());
            else if (OpenableColumns.SIZE.equals(columns[i])) row[i] = file.length();
        }
        result.addRow(row); return result;
    }
    public Uri insert(Uri uri, ContentValues values) { throw new UnsupportedOperationException("Read only"); }
    public int delete(Uri uri, String selection, String[] args) { throw new UnsupportedOperationException("Read only"); }
    public int update(Uri uri, ContentValues values, String selection, String[] args) { throw new UnsupportedOperationException("Read only"); }
}

package com.reelkeep.app;

import android.content.ClipData;
import android.content.Context;
import android.content.Intent;
import android.content.pm.ApplicationInfo;
import android.net.Uri;
import java.io.File;
import java.io.IOException;

/** Shares only the installed, signed, monolithic APK; never a catalog/archive. */
final class ApkSharing {
    static final String MIME = "application/vnd.android.package-archive";
    static String filename(Context c) {
        String version = "";
        try { version = c.getPackageManager().getPackageInfo(c.getPackageName(), 0).versionName; }
        catch (Exception ignored) {}
        return "Reelkeep" + (version == null || version.isEmpty() ? "" : "-" + version.replaceAll("[^0-9A-Za-z._-]", "")) + ".apk";
    }
    static File installed(Context c) throws IOException {
        ApplicationInfo app = c.getApplicationInfo();
        if (app.splitSourceDirs != null && app.splitSourceDirs.length != 0)
            throw new IOException("Установка состоит из нескольких APK. Поделиться этой сборкой нельзя.");
        File file = new File(app.sourceDir == null ? "" : app.sourceDir);
        if (!file.isFile() || file.length() == 0) throw new IOException("Установочный APK не найден");
        return file;
    }
    static Uri uri(Context c) {
        return new Uri.Builder().scheme("content").authority(c.getPackageName() + ".apkshare")
                .appendPath(filename(c)).build();
    }
    static Intent intent(Context c) throws IOException {
        installed(c);
        Uri uri = uri(c);
        Intent intent = new Intent(Intent.ACTION_SEND).setType(MIME)
                .putExtra(Intent.EXTRA_STREAM, uri)
                .putExtra(Intent.EXTRA_SUBJECT, filename(c))
                .addFlags(Intent.FLAG_GRANT_READ_URI_PERMISSION);
        intent.setClipData(ClipData.newRawUri(filename(c), uri));
        return intent;
    }
}
